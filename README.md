# Hiver SDE Intern Take-Home Assignment

## Project Overview

This project builds an AI customer-support agent that:

1. Classifies customer messages into intents.
2. Generates replies based on historical resolutions.
3. Decides whether to auto-handle or escalate to a human.

## Dataset

Customer Support on Twitter dataset.

## How to Run

```bash
pip install -r requirements.txt
python run.py
